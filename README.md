Задание 2
Приведите ответ в свободной форме:
Установлен и настроен Zabbix Agent на два хоста: локальный (на самом Zabbix Server) и удаленный (на отдельной виртуалке zabbix-agent-2). Оба агента успешно передают метрики на сервер по внутренней сети.

Заполните здесь этапы выполнения, если требуется:
1. Запущен и добавлен в автозагрузку локальный Zabbix Agent на стороне сервера.
2. На вторую виртуальную машину ("zabbix-agent-2") установлен изолированный пакет "zabbix-agent".
3. Отредактирован файл "/etc/zabbix/zabbix_agentd.conf" на втором хосте: в параметрах "Server" и "ServerActive" прописан внутренний IP-адрес первой машины.
4. В веб-интерфейсе Zabbix созданы карточки хостов, для удаленной машины указан её внутренний IP-адрес.
5. Проверен статус доступности хостов, данные начали поступать в раздел Latest Data.

Поле для вставки кода:
```bash
# Команда проверки лога успешного запуска на второй машине:
sudo tail -n 20 /var/log/zabbix/zabbix_agentd.log
```
